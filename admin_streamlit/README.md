# Streamlit-админка «Вектор»

Отдельная внутренняя операционная панель на Streamlit (`http://127.0.0.1:8501`), работающая поверх Headless Admin REST API основного сервиса (`/api/admin/*`).

## Возможности
- **Обзор и KPI:** GMV, комиссия 5%, шлюз СБП 1%, выплаты 94%, активные споры, динамика по дням и распределение анкет по каналам.
- **Споры и возвраты:** фильтр/поиск, выгрузка CSV, разбор открытых споров с 100% возвратом средств на баланс ученика или отклонением.
- **Заявки и эскроу:** управление статусами заявок (`pending`, `accepted`, `declined`, `refunded`) с автоматическим возвратом эскроу.
- **Модерация репетиторов:** верификация анкет (`verified`) и поднятие в топ (`bumpedToday`).
- **Выплаты НПД:** контроль сумм и проведение/отклонение выплат (`processing`, `succeeded`, `rejected`).
- **Пользователи и система:** смена ролей (`student`, `tutor`, `admin`), диагностика БД (SQLite / PostgreSQL 17), слои архитектуры и просмотр Outbox-событий.

## Быстрый запуск локально

```bash
# 1. Основной сервер FastAPI должен работать на :8770
./scripts/site_ctl.sh start

# 2. Запуск Streamlit-админки на http://127.0.0.1:8501
./scripts/admin_ctl.sh start
```

## Безопасность в продакшене

Задайте `ADMIN_API_TOKEN` в окружении основного сервера FastAPI (`vektor-main`), а в админке укажите тот же токен через `ADMIN_API_TOKEN` или в поле **X-Admin-Token** боковой панели.
