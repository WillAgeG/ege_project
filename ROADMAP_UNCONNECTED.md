# ROADMAP_UNCONNECTED.md — Архитектурный роадмап (5 LIVE + 4 частично LIVE + 3 в бэклоге) и контракты событий «Вектор ЕГЭ»

> [!IMPORTANT]
> Этот документ фиксирует **12 архитектурных контуров** экосистемы «Вектор ЕГЭ» (распределённой по **7 независимым репозиториям**: `Preparation :8770`, `vektor-api :8771`, `vektor-ui-kit :8772`, `vektor-postgres :5432`, `vektor-polars-engine`, `vektor-airflow :8085`, `vektor-grafana :3000`):
> - **5 контуров полностью подключены к живому сайту (`ПОДКЛЮЧЕНО (LIVE)`)**: **Item #1 (`Payments / YooKassa API v3`)** через `backend/yookassa.py`, `backend/api/payments.py` (СБП `0%` / карты РФ `+3%`, `Idempotence-Key`, чеки 54-ФЗ, allowlist IP + перепроверка `GET /v3/payments/{id}`, сверка в `backend/scheduler.py` и вкладка «💳 Пополнения ЮKassa» в `admin_streamlit/app.py`); **Item #3 (`Payouts & НПД`)** через `backend/payouts.py` (`YooKassaPayoutsClient`: B2C СБП `bank_id` + карты РФ/Мир, антифрод-холд, webhook `/api/payouts/yookassa/webhook`), `backend/npd_fns.py` (`FnsNpdClient`: проверка 12-значного ИНН и статуса НПД, регистрация/отмена чеков ФНС `partner` / `lknpd` / `demo`), `backend/api/payouts.py`, миграцию `20261123_0006` (`npd_receipts`) и управление в `admin_streamlit/app.py`; **Item #5 (`Dual-Write / PostgreSQL Auth & Docs` + `Admin REST & Outbox`)** через `databases/postgres/store.py` (`DualWriteDatabase`, `PostgresDatabase`, `create_store`, `outbox.kafka_outbox`), `backend/api/admin.py`, `frontend/core/api.js` и Streamlit-админку `admin_streamlit/` (`:8501`); **Item #10 (`S3 Media & Verification`)** через `backend/media_storage.py` (`local` + AWS SigV4 `s3`), `backend/api/media.py`, `frontend/core/api.js` (`EGE.api.media`, `EGE.api.verifications`), `tutor_verifications` / `media_assets` и вкладку «🎓 Проверка дипломов» в `admin_streamlit/app.py`; и **Item #12 (`Realtime & Calendar Sync`)** через `backend/realtime.py`, `backend/calendar_sync.py`, `frontend/core/realtime.js` и UI-Kit виджеты `EGE.kit.realtimeStatusPillHTML` / `EGE.kit.calendarSyncCardHTML` (в изолированном `@vektor-ege/ui-kit` v1.2.0, `27` карточек `/brandbook`).
> - **Ещё 4 контура подключены частично (`ЧАСТИЧНО LIVE`)**: **Item #2 (`Escrow Engine`)** — серверный эскроу в SQLite/PG и фоновый планировщик `backend/scheduler.py` (автозачисление `94%` репетитору / `5%` сервис + `1%` СБП и `98%` для своих учеников после урока при отсутствии спора, автоотмена просроченных заявок со 100% возвратом); **Item #4 (`Marketplace Server DB`)** — реальные анкеты `GET /api/tutors`, профиль репетитора `PUT /api/tutor/profile` и полная гидратация кабинета репетитора (`GET /api/bookings?scope=tutor`, `GET /api/tutor/summary`, без демо-фикстур при `DEV_DEMO_MODE=0`); **Item #8 (`Messenger Bots & OTP Gateways`)** — живой Telegram-бот `backend/telegram_bot.py` (`backend/api/telegram.py`), напоминания 24 ч / 1 ч и исходящая доставка OTP через Telegram Gateway API, WhatsApp Business API и SMS РФ (`SMS.ru` / `SMSC.ru`), без входящих ботов WhatsApp и MAX Bot API; и **Item #11 (`AI Study Analytics & Quotas`)** — персистентные квоты ИИ/лимиты (`rate_limit_hits`) и OTP (`phone_otp_codes`) в БД без кросс-когортной матрицы ФИПИ в Polars.
> - **Остальные 3 контура намеренно оставлены в отложенном бэклоге (`ОТЛОЖЕНО (BACKLOG)`)**: Clickstream батчинг (#6), внешний кластер Kafka/Redpanda (#7) и живые внешние парсеры Ykt.ru/TG/MAX (#9) — они спроектированы на уровне схем `vektor-postgres`, пайплайнов `vektor-polars-engine`, DAG-ов `vektor-airflow` и дашбордов `vektor-grafana`, чтобы боевой SPA (`frontend/app.js`) сохранял 100% автономность и zero-config запуск.

## 2. Канонический JSON-конверт событий (Items #5, #6, #7, #12)

Все события транзакционного аутбокса (`outbox.kafka_outbox`), realtime-хаба (`backend/realtime.py`) и пользовательской телеметрии (`telemetry.user_events`) используют единый неизменяемый конверт **Canonical Event Envelope (`v1`)**:

```json
{
  "event_id": "019639a4-7c8b-7000-8a12-4f91b2c0d3e4",
  "event_type": "market.bid.submitted",
  "occurred_at": "2026-11-15T14:50:12.345Z",
  "user_id": "usr_9f8e7d6c5b4a",
  "session_id": "ses_3a2b1c0d9e8f",
  "role": "student",
  "view": "market",
```

### Обязательные поля конверта

| Поле | Тип | Описание и инварианты |
|---|---|---|
| `event_id` | `string (UUIDv7 / UUIDv4)` | Глобально уникальный идентификатор события; первичный ключ идемпотентности при дедупликации в `telemetry.user_events`, `outbox.kafka_outbox` и Polars `LazyFrame`. |
| `event_type` | `string` | Имя события в нотации `<domain>.<entity>.<action>` (например: `auth.user.registered`, `docs.document.updated`, `market.bid.created`, `calendar.slots.synced`, `payments.escrow.captured`). |
| `occurred_at` | `string (ISO-8601 UTC)` | Время возникновения события в UTC (`YYYY-MM-DDTHH:mm:ss.sssZ`). Локальный пояс (`UTC+9` Якутск / `UTC+3` Москва) передаётся в `payload`. |
| `user_id` | `string \| null` | Идентификатор пользователя из `oltp.users` (`null` для неавторизованного гостя). |
| `session_id` | `string` | Идентификатор клиентской или серверной сессии для склейки воронки от первого визита на `/landing` до оплаты. |
| `role` | `"student" \| "tutor" \| "guest" \| "system"` | Активный продуктовый режим инициатора события. |
| `view` | `string` | Текущий экран SPA из `VIEWS` (`landing`, `market`, `cabinet`, `fees`, `study`, `quiz`, `essay`, `stats`, `brandbook` и др.) или `"backend"` для серверных задач. |
| `payload` | `object (JSONB)` | Типизированное тело события, соответствующее контракту одного из 5 топиков Kafka. |
| `schema_version` | `string (SemVer)` | Версия схемы конверта (текущая — `"1.0.0"`). |
