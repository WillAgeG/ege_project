# Шаблоны тестовых заданий ОГЭ и ЕГЭ в курсах (`course-templates.js`)

Библиотека `frontend/views/course-templates.js` (`EGE.courseTemplates`) задаёт исчерпывающий набор из **13 интерактивных форматов**, покрывающих все типы заданий ОГЭ и ЕГЭ по всем школьным предметам, включая проверку кода на Python.

| # | `qtype` | Формат задания | Где применяется на ОГЭ/ЕГЭ | Почему удобно ученику |
|---|---|---|---|---|
| 1 | `single` | Выбор 1 ответа | Русский №4–6 (база), ОГЭ, История, Биология, Химия | Крупные карточки на всю ширину с нумерацией `1..4` |
| 2 | `multi` | Выбор нескольких ответов | Русский №4, №9–12, №16; Биология; Химия; ОГЭ | Поддержка точного режима (`exactCount`) со счётчиком `выбрано K/N` и открытого списка |
| 3 | `input` | Краткий ввод (`word` / `number` / `digits`) | ОГЭ/ЕГЭ Математика, Русский №5, №7, №22–26 | В `number` принимает `,` и `.` (`0,25 = 0.25`); в `digits` поддерживает `anyOrder` |
| 4 | `match` | Соответствие (А–Г ↔ 1–5) | Русский №8, №21; Математика №11; Биология; Химия; ОГЭ | Строки с крупными кнопками-цифрами + живой код ответа + построчный разбор |
| 5 | `order` | Последовательность | Биология №12, №14, №19; Химия №21; История №1 | Нажатие карточек по порядку `1 → 2 → 3 → 4` без неудобного drag-and-drop |
| 6 | `gaps` | Пропуски в тексте (клик-подстановка) | Русский №9–12, №15 (Н/НН), ОГЭ №5–6 | Клик по слоту `{{0}}` и подстановка чипа с автопереходом к следующему пропуску |
| 7 | `punct` | Запятые прямо в предложении | Русский ЕГЭ №17–20, ОГЭ №3 | Цифры `{{1}}`, `{{2}}` нажимаются в самом тексте, визуально ставится запятая |
| 8 | `classify` | Сортировка по категориям / Верно–Неверно | Русский №13–14, Химия №18–20, Биология | Переключатели категорий напротив каждой короткой строки |
| 9 | `self` | Развёрнутый ответ 2-й части + критерии ФИПИ | ОГЭ/ЕГЭ 2-я часть (Математика, Биология, Химия, Русский №27) | Черновик ответа → эталон ФИПИ → чек-лист критериев с подсчётом баллов |
| 10 | `multi_input` | Несколько отдельных полей ответа | Информатика ЕГЭ №17, 25–27; Физика (`val ± err`); ОГЭ | Подписанные отдельные поля вместо угадывания разделителя |
| 11 | `table` | Интерактивная таблица с пропусками | Информатика ЕГЭ №2, Химия №23, ОГЭ Математика №1–5 | Заполнение ячеек кликом по вариантам (`0/1`) или коротким вводом прямо в таблице |
| 12 | `text_pick` | Выбор предложений в пронумерованном тексте | Русский ЕГЭ №1–3, №23–26; ОГЭ №2–3, №6 | Кликабельные пронумерованные предложения прямо внутри текста |
| 13 | `code` | Задача на Python с проверкой на тестах | Информатика ЕГЭ №5, 8, 12, 14–17, 23–27 и ОГЭ №15.2 / №16 | Редактор кода + безопасный запуск через `POST /api/courses/run-python` |

---

## Серверная песочница Python (`POST /api/courses/run-python`)
- Бэкенд-роутер: `backend/api/courses.py`.
- Многоуровневая изоляция:
  1. Rate-limit `20` запусков в минуту на IP.
  2. AST-валидатор разрешает только безопасные модули (`math`, `itertools`, `functools`, `collections`, `string`, `re`, `bisect`, `heapq`, `fractions`, `decimal`, `statistics`, `random`, `operator`) и блокирует dunder-атрибуты (`__class__`, `__globals__`, …), `open`, `exec`, `eval`, `os`, `sys`, `subprocess` и т. д.
  3. Выполнение в отдельном процессе `python3 -I` с белым списком `__builtins__`, отдельным временным каталогом и жёстким таймаутом `2.0` сек на тест.
  4. Для тестов с `hidden: true` в ответ не передаются `stdin`, `expected` и `actual` — только статус `passed` и время.

## Примеры JSON для новых шаблонов (`10–13`)

### 10. `multi_input`
```js
{
  id: "inf17-1",
  kind: "test",
  qtype: "multi_input",
  prompt: "Найдите количество чётных чисел и максимальное из них:",
  fields: [
    { label: "Количество", subtype: "number", answer: ["3"] },
    { label: "Максимум", subtype: "number", answer: ["18"] }
  ],
  explain: "Чётные: 12, 18, 14."
}
```

### 11. `table`
```js
{
  id: "inf2-1",
  kind: "practice",
  qtype: "table",
  prompt: "Заполните таблицу истинности:",
  headers: ["A", "B", "A and B", "A or B"],
  rows: [
    ["0", "1", { slot: 0, choices: ["0", "1"], answer: ["0"] }, { slot: 1, choices: ["0", "1"], answer: ["1"] }]
  ],
  explain: "0 and 1 = 0; 0 or 1 = 1."
}
```

### 12. `text_pick`
```js
{
  id: "r25-1",
  kind: "test",
  qtype: "text_pick",
  multi: false,
  prompt: "Выберите предложение, связанное с предыдущим местоимением:",
  sentences: ["(1) Текст...", "(2) Вода...", "(3) В ней..."],
  answer: [2],
  explain: "Предложение (3) содержит местоимение «ней»."
}
```

### 13. `code` (Python)
```js
{
  id: "py-1",
  kind: "practice",
  qtype: "code",
  lang: "python",
  prompt: "Выведите сумму всех чётных чисел массива.",
  starterCode: "n = int(input())\nnums = list(map(int, input().split()))\nprint(sum(x for x in nums if x % 2 == 0))",
  tests: [
    { stdin: "5\n1 2 3 4 6\n", expected: "12", hidden: false },
    { stdin: "4\n1 3 5 7\n", expected: "0", hidden: true }
  ],
  explain: "Используем filter / генератор с условием x % 2 == 0."
}
```
